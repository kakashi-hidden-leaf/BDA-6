Aim: To create and analyze a student friendship network in R and identify communities using the
Louvain community detection algorithm

Objectives:
• Represent friendship relationships as a graph.
• Visualize nodes and edges using the igraph package.
• Calculate the degree of each node.
• Detect communities using the Louvain algorithm.
• Interpret community membership and modularity.

Introduction:
Social Network Analysis studies relationships among people, organizations, devices, or other entities. A
social network is represented as a graph in which entities are vertices or nodes and relationships are edges.
In this experiment, six students are nodes and seven friendship relationships are undirected edges.
Community detection finds groups of nodes that are more densely connected internally than with the rest
of the network. The Louvain algorithm is a modularity-based method. It repeatedly improves the grouping
of nodes to obtain a partition with higher modularity

#system requirements
Requirement                     Specification
Operating system                Windows 10 or Windows 11
Software                        R and RStudio Desktop
R package                       igraph
Installation command            install.packages("igraph") - execute once
Loading command                 library(igraph) - execute in every new session 

Result:
The friendship network was created and analyzed successfully. The Louvain algorithm detected two
communities: {A, B, C} and {D, E, F}. The modularity score obtained was 0.3571429.


#code
library(igraph)

friendships <- data.frame(
  from = c("A", "A", "B", "C", "D", "D", "E"),
  to   = c("B", "C", "C", "D", "E", "F", "F")
)
print(friendships)

social_network <- graph_from_data_frame(friendships, directed = FALSE)
print(social_network)

set.seed(10)
network_layout <- layout_with_fr(social_network)

plot(
  social_network,
  layout = network_layout,
  vertex.color = "skyblue",
  vertex.size = 35,
  vertex.label.color = "black",
  vertex.label.cex = 1.2,
  edge.color = "gray",
  edge.width = 2,
  main = "Student Friendship Network"
)

node_degree <- degree(social_network)
print(node_degree)

communities <- cluster_louvain(social_network)
print(communities)

community_membership <- membership(communities)
print(community_membership)

community_colors <- c("tomato", "skyblue")[community_membership]

plot(
  social_network,
  layout = network_layout,
  vertex.color = community_colors,
  vertex.size = 35,
  vertex.label.color = "black",
  vertex.label.cex = 1.2,
  edge.color = "gray",
  edge.width = 2,
  main = "Communities Detected Using Louvain Algorithm"
)

legend(
  "topleft",
  legend = c("Community 1", "Community 2"),
  pch = 21,
  pt.bg = c("tomato", "skyblue"),
  pt.cex = 2,
  bty = "n"
)

cat("Number of communities:", length(communities), "\n")
cat("Modularity score:", modularity(communities), "\n")
